## 1. Supabase төсөл (≈10 минут)

1. **supabase.com** → **New project** → нэр: `moriton-parade`, бүс: **Northeast Asia (Seoul)** эсвэл **Tokyo** → нууц үг өгөөд үүсгэнэ.
2. **SQL Editor → New query** → `supabase/schema.sql` файлын агуулгыг бүхэлд нь хуулж тавина → **Run**.
   - Админ имэйл нь `khongor95@gmail.com`. Өөр бол файлын доод хэсгийн `insert into public.parade_staff` мөрийг засаад ажиллуулна.
3. **Authentication → Users → Add user → Create new user** → дээрх имэйл + нууц үг, **Auto Confirm User** ✓.
4. **Edge Functions → Deploy a new function → Via Editor**
   - Function name: **`parade`** (яг ингэж)
   - `supabase/functions/parade/index.ts` файлын агуулгыг бүхэлд нь тавина → **Deploy function**.
   - Дараа нь функцийн **Details / Settings** хэсэгт **«Verify JWT»** (Enforce JWT verification) тохиргоог **УНТРААЖ** хадгална. ⚠ Үүнийг унтраахгүй бол сайт ажиллахгүй, QPay-ийн мэдэгдэл ирэхгүй.
5. **Edge Functions → Secrets** → доорх утгуудыг нэмнэ:

| Нэр | Утга |
|---|---|
| `QPAY_CLIENT_ID` | QPay-ээс өгсөн merchant username |
| `QPAY_CLIENT_SECRET` | QPay-ээс өгсөн password |
| `QPAY_INVOICE_CODE` | QPay-ээс өгсөн нэхэмжлэхийн код (жишээ `MORITON_INVOICE`) |
| `SMTP_USER` | Илгээх Gmail хаяг (жишээ `parade.moriton@gmail.com`) |
| `SMTP_PASS` | Тэр Gmail-ийн **App password** (16 үсэг, доорх 4-р хэсгийг үз) |
| `MAIL_FROM` *(заавал биш)* | `Морьтон Парад <parade.moriton@gmail.com>` |

   QPay-ийн жинхэнэ түлхүүр ирээгүй байхад туршихдаа зөвхөн `QPAY_MODE` = `sandbox` гэж нэмж болно (QPay-ийн туршилтын орчин).

6. **Project Settings → API Keys** (эсвэл дээд талын **Connect** товч) → **Project URL** болон **Publishable key** (`sb_publishable_…`, эсвэл хуучин «anon public» key)-г хуулж авна.

## 2. GitHub дээр байршуулах

1. `js/config.js` файлыг нээж 2 утгыг тавина:
   ```js
   SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
   SUPABASE_KEY: 'sb_publishable_xxxxxxxx',
   ```
   (Энэ түлхүүр нууц биш — хөтчид харагдах зориулалттай. Бүх өгөгдлийг сервер хамгаална.)
2. GitHub → **New repository** (жишээ `parade`, Public) → **Add file → Upload files** → энэ хавтсын бүх файл, хавтсыг (`css`, `js`, `img`, `supabase`…) **чирж** оруулна → **Commit changes**.
3. Repo → **Settings → Pages → Deploy from a branch → `main` / `(root)` → Save**.
4. 1–2 минутын дараа: `https://<нэр>.github.io/parade/`

## 3. Эхний шалгалт (заавал)

1. `…/parade/admin.html` → имэйл, нууц үгээр нэвтэрнэ.
2. **Тохиргоо** таб:
   - **Парад эхлэх цаг** — анхдагчаар **10:00** гэж тавьсан. Бодит цагаа оруулна (нүүрний тоолуур үүгээр явна).
   - **Мэдэгдэл очих имэйл** — хүн тасалбар авах бүрт энд имэйл ирнэ (жишээ `munkhtsetseg@moriton.mn`).
   - **QPay шалгах** → «амжилттай» гарах ёстой.
   - **Туршилтын имэйл** → өөрийн хаяг руу илгээж, QR зурагтай ирсэн эсэхийг шалгана.
3. Утаснаасаа 1 тасалбар авч QPay-ээр төлж үзнэ → тасалбар гарч, имэйл ирнэ. Админ → **Уншуулах** → QR-ыг уншуулна. Дараа нь **Захиалга** таб дээрээс тэр захиалгыг **Цуцлах** (дугаар нь чөлөөлөгдөнө).

## 4. Gmail App password авах

1. myaccount.google.com → **Security** → **2-Step Verification**-ийг асаана.
2. myaccount.google.com/apppasswords → нэр: `Parade` → **Create** → гарсан 16 үсэгтэй кодыг `SMTP_PASS`-д тавина.
3. Gmail өдөрт ~500 имэйл илгээнэ — 600 тасалбарт хангалттай. (Өөр сонголт: resend.com-ийн `RESEND_API_KEY` + баталгаажсан домэйн.)

## 5. QPay бэлэн биш бол

Админ → Тохиргоо → **Дансны мэдээлэл**-ийг бөглөнө (банк, данс, хүлээн авагч). QPay-ийн түлхүүр тохируулаагүй үед сайт автоматаар **дансаар төлөх** горимд шилжинэ: худалдан авагч гүйлгээний утга дээр захиалгын кодоо (`MP-XXXXXX`) бичнэ, та **Захиалга → Баталгаажуулах** дармагц тасалбар олгогдож имэйлээр очно. QPay-ийн түлхүүрийг нэмэнгүүт QPay горим руу автоматаар шилжинэ.

## 6. Парадын өдөр

- **Үүдний ажилтан:** Тохиргоо → «Ажилтан, эрх» → имэйл + нууц үг + **Ажилтан** эрхээр нэмнэ. Тэд утсаараа `admin.html`-ээр орж зөвхөн **Уншуулах**, **Самбар** харна.
- **Уншуулах:** Орох / Хоол / Ундаа горимоо сонгоод **Камер асаах**. Ногоон = орж болно, шар = аль хэдийн уншуулсан (цагтай), улаан = хүчингүй / олдсонгүй. Камер ажиллахгүй бол тасалбарын **дугаарыг** бичиж шалгана.
- **Үүдэн дээр бэлнээр зарах:** **Гараар олгох** → нэр, тоо, төлбөрийн хэлбэр → QR тасалбар шууд гарна (имэйл бичвэл имэйлээр ч очно).
- **Сугалаа:** **Сугалаа** таб → шагнал сонгох → «Зөвхөн ирсэн» → **Сугалах**. **Дэлгэц дүүрэн** товчоор проектор дээр харуулна. Нэг тасалбар 2 удаа хожихгүй; хожигч ирээгүй бол «Хүчингүй болгох».
- **Excel:** Захиалга, Тасалбар табуудаас CSV татаж Excel-ээр нээнэ.

## 7. Дүрэм, хамгаалалт

- Тасалбарын дугаар 11111-ээс дараалж олгогдоно (төлбөр баталгаажсан дарааллаар). Нийт 600-аас хэтрэхгүй — нэг зэрэг олон хүн авсан ч давхардахгүй (өгөгдлийн санд түгжээтэй).
- Төлбөр хүлээж буй захиалга суудлыг **20 минут** барина (Тохиргооноос өөрчилнө). Хугацаа дуусвал суудал буцаж нээгдэнэ. Хугацаа дууссаны дараа төлсөн ч суудал байвал тасалбар олгоно, суудал дууссан бол «Буцаалт хэрэгтэй» төлөвт орж админд имэйл очно.
- Нэг утаснаас 2-оос олон төлөгдөөгүй захиалга үүсгэж суудал барихыг хориглоно.
- QR код бүр таах боломжгүй 20 тэмдэгттэй. Нэг QR-аар нэг л удаа орно (2 дахь удаа шар анхааруулга).
- Хөтчөөс өгөгдлийн сан руу шууд хандах боломжгүй (RLS) — бүх үйлдэл Edge Function-аар, админ үйлдэл нэвтрэлт + эрхээр шалгагдана.
- Төлбөрийг QPay-ийн callback болон хуудасны шалгалт хоёулангаар нь QPay API-аас дахин шалгаж баталгаажуулна (callback-д дангаар нь итгэхгүй).

## 8. Асуудал гарвал

| Шинж | Шалтгаан / шийдэл |
|---|---|
| Сайтын дээр шар «Тохиргоо дутуу» | `js/config.js`-д URL, key оруулаагүй |
| «Сервертэй холбогдож чадсангүй» эсвэл 401 | Функцийн нэр `parade` биш, эсвэл **Verify JWT** унтраагаагүй |
| «QPay нэхэмжлэх үүсгэж чадсангүй» | QPay secrets буруу → Админ → QPay шалгах. Edge Functions → parade → **Logs** |
| Имэйл ирэхгүй | Туршилтын имэйл → алдааны мессежийг уншина (App password буруу байх магадлалтай). Spam хавтсыг шалга |
| Админ: «эрхгүй байна» | Тэр имэйл `parade_staff` хүснэгтэд алга → SQL-ийн доод мөрийг засаж дахин ажиллуул |
| Тасалбарын линк буруу хаяг руу заана | Тохиргоо → **Сайтын хаяг**-ийг GitHub Pages-ийн хаягаар засна |

Функцийн кодыг шинэчлэх бол Edge Functions → parade → **Code** → шинэ агуулгыг тавиад **Deploy**.
